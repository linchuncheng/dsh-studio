### 这一批（0.9.17）具体做了什么

**第 4 条**：`/projects/save`、`/experts/save`、`/teams/save`、`/bots/save`、`/suite/save`
要求名称非空，`POST {} ` 现在 400（「项目名称不能为空」等），不再造出 `proj-8ac46c`。

**第 6 条**：`/task/create` 对**非缺陷**卡要求 `requirementId`，否则 400「建卡要挂到一条需求上」；
缺陷仍可不挂（缺陷常常还没有需求）。这样卡一定有 `code`，需求侧也能看到它。

**第 7 条**：没配环境时，从面板/接口触发的用例执行**回退到宿主自身地址**跑一遍，不再直接

解析逻辑抽成 `resolveTestingEnv()` 纯函数，4 条单测覆盖：默认环境优先 / 回退自身 / 无来源明确失败 / 配置缺字段不炸。

**第 10 条**：`/market` 目录为空时返回一条可照做的 `hint`（面板空态直接显示它）：
> 市场目录还没配：面板里点「＋ 添加条目」，或 POST /studio-api/market/save { "item": { "name": …, "spec": …, "description": … } }
